# 예시 세트 ex-v1 (lemin 작성)

사람이 직접 쓴 가상 리뷰 예시 (지시서 sim/review-product-import 2단계, 2026-10-16).
아래 코드블록의 `____` 를 모두 채우면 `rsim bench --examples ex-v1` 로 돌릴 수 있다(빈칸이 남아 있으면 멈춘다).
실제 쇼핑몰 후기를 옮겨 적지 말고 새로 쓴 문장만 넣는다(공개 저장소 + Bedrock 으로 전송).

seed_sources: aihub, handwritten

칸별 작성 안내 (p5.8 bench 20건에서 틀린 곳 위주, 이 안내는 프롬프트에 안 들어간다)
- 중립 11칸: 버린 리뷰 1위가 "중립인데 긍정으로 씀"이었다. "예뻐요, 편해요, 좋아요"가 섞이지 않게,
  "보통이에요, 무난해요, 그냥 그래요" 또는 장점과 단점을 같은 무게로 쓴 문장이 좋다.
- 1문장 칸: 문장 수 초과가 45%였다. 속성 2~3개를 쉼표·연결어미(~고, ~는데)로 한 문장에 잇는 예.
- 명세 밖 칸: 명세가 "배송 긍정" 하나뿐일 때 나쁜 예는 "배송 빠르고 옷도 예뻐요"처럼 다른 속성을 덧붙인 문장,
  좋은 예는 배송만 말한 문장. 나쁜 예를 넣으면 모델이 따라 할 수 있으니 "나쁜 예" 표시를 꼭 남긴다.
- 말투 칸(장단점, 재구매, 음슴체): 괄호 안 명세에 맞게 1~2문장.
- 전체 줄 수는 지금 정도(약 12줄)로 유지한다. 줄이 늘면 매 호출 입력 토큰이 그만큼 는다.

```text
- 중립(좋다/나쁘다로 기울지 않게)
  재질·촉감 "재질도 괜찮고 만졌을 때 까끌함이 없어요." / 사이즈·핏 "사이즈가 너무 크지 않고 적당하고 몸에 잘 맞아요." / 색상·디자인 "색상도 너무 진하지 않고 적당하네요. 디자인도 촌스럽지 않아요." / 품질·내구성 "마감도 괜찮고 마감이 덜 된 부분도 없네요."
  가격·가성비 "가격도 적당해요." / 냄새 "새 옷 특유의 냄새가 나는 것도 없어요." / 세탁·관리 "빨고 다시 입어도 줄어드는 부분은 없었어요." / 활용성·사용감 "어디든 적당히 사용하기 괜찮네요."
  배송 "배송도 무난하게 온 것 같아요." / 포장 "포장이 찢어지거나 대충 넣은 느낌은 없네요." / 교환·환불·CS "교환 응대도 늦지 않게 해주셨습니다."
- 1문장, 속성 2~3개: "옷 안 촉감이 부드러워서 입을 때 기분이 좋아지고 디자인도 이뻐서 정말 마음에 들어요 ㅎㅎ" / "디자인도 이쁘고 사이즈도 정말 잘 맞는데 마감이.... 덜 되어서 왔네요."
- 명세 밖 속성 덧붙이지 않기 (명세: 배송 긍정만): 나쁜 예 "배송도 빠르고 옷도 마음에 들어요." → 좋은 예 "배송이 정말 빠르게 왔네요. 감사합니다."
- 장단점 말투 (색상·디자인 긍정, 사이즈·핏 부정): "제가 정말 원하던 대로의 색깔이고 정말 이쁜데 사이즈가 너무 헐렁해서 핏이 안 살아요 ㅠㅠ"
- 재구매 말투 (별점 2, 품질·내구성 부정): "옷이 금방 헤져서 다시는 안 살 것 같아요."
- 짧은 음슴체 (배송 긍정, 사이즈·핏 부정): "배송은 빨랐는데 사이즈가 실측치보다 작음"
- 상품 정보 활용 (소재 얇은 린넨, 재질·촉감 부정): "린넨 소재를 사용한 옷이라 그런지 재질이 너무 얇아서 속비침이 너무 심해요..."
```
