# 직접 작성한 리뷰 (실제 말투 흉내)

CSV 파일(UTF-8)은 이 폴더가 아니라 **`.local/handwritten/`** 에 넣고 `rsim seeds` 를 다시 실행하면 시드에 들어갑니다.
`.local/` 은 `.gitignore` 에 들어 있어 저장소에 올라가지 않습니다. 이 폴더에는 형식 설명과 빈 양식만 둡니다.

| 컬럼 | 필수 | 설명 |
|---|---|---|
| text | O | 리뷰 본문 |
| category | | 여성의류 / 남성의류 / 패션슈즈 / 잡화 (비우면 모든 카테고리 예시로 사용) |
| rating | | 1~5 |
| aspects | | `사이즈·핏:부정;배송:긍정` 처럼 `속성:감성` 을 `;` 로 연결 (비워도 됨) |

주의: 실제 쇼핑몰 후기를 그대로 옮겨 적은 글(review-analysis/private/ 자료)은 넣지 마세요.
Bedrock(외부 서비스)으로 전송되기 때문입니다. 실제 말투를 참고해 **새로 쓴** 글만 넣습니다.
