# AI Hub 패션 속성 기반 감성분석 데이터와 우리 라벨 가이드 비교 (2026-10-12)

대상: `aihub_dataset/`(AI Hub, 패션 도메인 속성 기반 감성분석). 수치는 쇼핑몰 후기 40,400건(Training+Validation) 기준이고 로컬에서만 계산했다.
원문은 옮기지 않았다(재배포 조건 미확인). 우리 기준은 `docs/absa-label-guide.md`(R1~R21).

## 1. 데이터 구조
| 항목 | AI Hub | 우리 |
|---|---|---|
| 단위 | **구절(span) 단위**: 후기마다 `Aspects` 목록에 (속성, 감성 구절, 극성) 여러 개 | 후기 단위: 속성마다 감성 1개, 같은 속성은 한 번만(R20) |
| 극성 | 1(긍정) / 0(중립) / -1(부정) | 긍정 / 부정 / 중립, **미언급은 출력 안 함** |
| 후기당 항목 | 최소 2개 (평균 3.4개). **속성 1개짜리 후기는 사실상 없음** (고유 속성 1개 후기는 6%이고 그것도 구절 2개 이상) | 1개짜리 후기가 흔함 |
| 같은 속성 반복 | 16,278건(후기 속성 반복), 그중 3,875건은 극성 충돌 | 충돌하면 중립(R14) |
| 속성 체계 | 카테고리별 18종 (아래 2장) | 10종 고정 |
| 서비스 속성 | **없음** (배송·포장·CS·세탁 없음) | 배송·포장·교환환불CS·세탁 |
| 중립 비율 | **3.9%** (쇼핑몰) | 합성 평가셋은 약 1/3 |
| 극성 분포 | 긍정 67%, 부정 29%, 중립 4% (리뷰 별점 100점이 66%) | 속성별로 균형을 맞춰 설계 |

## 2. 속성 체계 차이
- 여성·남성의류: 사이즈, 핏, 길이, 신축성, 두께, 소재, 촉감, 디자인, 색상, 품질, 마감, 가격, 냄새, **착용감, 기능, 무게, 활용성, 제품구성**
- 패션슈즈: **착화감**, 치수/사이즈, 디자인, 가격, 품질, 내구성, 소재, 색상, 굽, **무게, 기능성, 사용성, 제품구성**
- 잡화: 디자인, 사이즈/폭/길이/두께, 가격, 품질, 소재, 색상, 내구성, **사용성/편의성, 무게, 제품구성, 수납, 기능성, 착용감**

| 우리 속성 | AI Hub에서 대응하는 속성 | 비고 |
|---|---|---|
| 재질·촉감 | 소재, 촉감, 두께 | R1과 일치 |
| 사이즈·핏 | 사이즈, 치수/사이즈, 사이즈/폭/길이/두께, 핏, 길이 (신축성은 우리는 여기, AI Hub는 별도) | 신축성·착용감은 대응 불분명 |
| 색상·디자인 | 디자인, 색상 | R3과 일치 |
| 품질·내구성 | 품질, 내구성, 마감 | R4와 대체로 일치 (아래 3장) |
| 가격·가성비 | 가격 | R6과 일치 |
| 냄새 | 냄새 | 쇼핑몰 후기에서 거의 없음(475건, 대부분 부정) |
| 세탁·관리, 배송, 포장, 교환·환불·CS | **없음** | 정답 비교 불가 |
| (없음) | 기능, 착용감, 착화감, 무게, 활용성, 제품구성, 사용성, 굽, 수납 | **우리 체계에 없는 속성** (전체 구절의 약 33%) |

→ 대응되는 6개 속성만 비교 가능하고, 우리 체계에 없는 속성이 든 후기는 정답이 불완전하다. 그래서 평가·학습에서 **모든 속성이 매핑되는 후기만**(쇼핑몰 12,029건) 썼다. 이 필터는 "대응 속성만 언급한 후기"로 분포를 치우치게 한다.

## 3. 라벨 기준이 다른 곳 (우리 규칙과 충돌)
수치는 구절(span) 기준이다.

| 우리 규칙 | AI Hub 실제 | 충돌 정도 |
|---|---|---|
| **R5 세탁 후 줄어듦 → 세탁·관리** | 세탁 관련 구절 901건 중 품질 534, 소재 258. '줄어' 구절 149건 중 **품질 129건**(87%), 사이즈 7건 | **높음**. AI Hub에서는 세탁 문제가 품질이다. 이 데이터로 학습하면 세탁 줄어듦을 품질로 뽑는다 (실제로 사람 후기 EX29에서 발생) |
| R4 이염·물빠짐 → 품질·내구성 | 이염 구절 138건 중 품질 124건 | **일치** |
| R4 먼지·보풀·실밥 → 품질·내구성 | 682건 중 품질 420, 마감 167, 소재 81 | 대체로 일치 (소재 12%는 불일치) |
| 냄새 → 냄새 | 냄새 관련 구절 677건 중 냄새 448, **품질 211건(31%)** | 부분 충돌 |
| **R10 추측·조언·권유는 미언급** | 권유·조언 표현 구절 960건이 **그대로 속성·극성으로 라벨**(사이즈·치수 437건 등, 긍정 49%, 부정 39%, 중립 12%). 추측 표현("~것 같다", "~듯하다") 구절 5,930건도 라벨됨 | **높음**. AI Hub는 추측·조언에도 극성을 붙인다. 학습하면 조언문에서 속성을 뽑는다 (EX17, EX10에서 발생) |
| **R9 코디·조합은 속성 아님** | 코디 구절 225건 중 활용성 146, 디자인 57 | 중간. 활용성은 우리 체계에 없어 매핑 제외, 디자인 57건은 충돌 |
| R8 평가 없는 사실은 미언급 | 사실 서술형 구절(소재 설명, 제품 구성 등)도 라벨되고 중립이 많음 | 중간. 소재 중립 구절의 예: 소재 종류만 말한 것 |
| **R14~R16 중립 기준** | 중립은 4%뿐이고, 중립 구절의 빈출어가 '좀·조금·약간·살짝'(사이즈류에서 완화어가 든 구절의 극성은 **부정 55~77%, 중립 16~28%**). '무난·보통'이 든 구절은 오히려 소수. 같은 크기 불만이라도 "커요"가 든 구절은 부정 86%, 중립 12% | **높음**. AI Hub의 중립은 '약한 불만/완화 표현'이 다수. 우리의 중립은 '보통·무난' 또는 '장단점 혼재'. 학습하면 사이즈·핏에서 중립이 늘어난다 (AI Hub 중립 재현율 23%→57%) |
| R16 최종 평가를 따름 | 한 후기에서 같은 속성 극성 충돌 3,875건을 구절별로 분리해 둠 | 우리 평가에 맞추려면 후처리 필요 (충돌=중립으로 병합했지만 R16대로면 긍정/부정이 될 수 있다) |
| R6 가격 대비 품질 → 가격+품질 둘 다 | '가격대비' 구절 4,474건 중 가격 3,656(82%), 품질 346 | 대체로 일치 |
| R20 속성 한 번만 | 같은 속성이 여러 구절로 반복 (후기 속성 반복 16,278건) | 병합 규칙 필요 (현재: 충돌이면 중립) |

## 4. 모델 평가에 미친 영향
- AI Hub 점수는 우리 규칙이 아니라 AI Hub 규칙 기준이다. 특히 **사이즈·핏 감성**(약한 불만=중립)과 **조언·추측문**이 영향을 준다.
- v0(합성만 학습)은 AI Hub 중립의 77%를 부정/긍정으로 예측해 감성 정확도가 낮게 나왔다(86%). v2(AI Hub 추가)는 AI Hub 중립을 학습해 90.5%가 됐지만, 사람 후기(우리 규칙)에서는 혼합 후기를 중립으로 바꾸는 오류가 늘었다(EX27, EX28).
- 세탁·크롭 등 용어는 AI Hub가 다르게 라벨해서 v2가 사람 후기에서 틀렸다(EX29).

## 5. 처리 방안 (v3 제안)
1. **매핑 보강**: 세탁/줄어듦 구절은 AI Hub 품질 라벨을 세탁·관리로 바꾸는 규칙 변환을 쓰거나 해당 후기는 제외. 냄새 구절의 품질 라벨 중 냄새가 주제인 것은 냄새로 변환.
2. **조언·추측·권유 구절 제외**: 해당 표현이 든 구절(권유·추측 합쳐 약 6,900건, 일부 중복)은 학습에서 뺀다(R10).
3. **중립 정책**: 완화어("좀/조금/약간/살짝")만으로 중립이 된 사이즈류 구절은 중립 대신 부정으로 변환하거나 제외하고, '무난·보통' 구절만 중립으로 둔다(R15, R18).
4. **코디 구절 제외**: 코디·조합 구절은 매핑에서 제외(R9).
5. **분포 보정**: 속성 1개짜리 후기와 서비스 속성 후기는 합성·사람 후기로 보충.
6. 위 변환을 거친 AI Hub 후기를 v2 학습에 쓰고, 사람 평가셋과 합성 500건으로 악화 여부를 본다.
