상태: 운영 반영 준비

증상: 백필 PARTIAL metadata와 제목은 보이지만 기본 상품 선택이 약 7만 개 상품 목록을 먼저 내려받아 차트 표시가 늦었다. 이후 일별 원본 집계 105,038행도 내려받는 구조였다.
