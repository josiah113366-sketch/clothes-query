# 상품 판매 Gold 조회 지연 보완

상태: 운영 반영 준비

상품 판매 첫 화면에서 전체 상품 목록과 상품별 Gold 원본 14만여 행을 가져오던 경로를 변경한다. 동일 거래 Gold run_id의 날짜별 전체 합계, 상품별 판매 금액 상위 20개, 디자인별 상위 20개를 Athena에서 집계해 표시한다. 결제일 기준 기간 선택, 이전 기간 대비, 수량·금액 추이와 PARTIAL·보류 안내는 유지한다. 상위 목록은 전체 목록으로 표시하지 않는다.

## 작업 결과

변경: `dashboard/gold_a_io.py`, `dashboard/pages_product/product_sales.py`, 관련 회귀 시험. Bronze·Silver·Spark·Gold 결과는 변경하지 않았다.

확인: Gold A 회귀 44개 통과. 실제 거래 Gold `trade-gold-recover-20261026t045917z`를 읽어 날짜별 6행, 상위 상품 20행, 상위 디자인 20행을 반환했고 전체 저장된 합계는 판매 수량 421,577개·판매 금액 10,838,840,300원이었다. 실제 화면 배포 및 브라우저 검증은 별도 확인한다.
