# 운영 거래 Gold 조회 한도 보완

상태: 운영 반영 준비

실제 거래 Gold `trade-gold-recover-20261026t045917z`의 상품별 집계는 140,807행이다. 운영 조회 한도 100,000행으로는 기존 화면에서 전체 상품을 조회할 수 없다.

`GoldAReader.read`의 거래 지표 조회에만 최대 250,000행을 허용한다. 리뷰·퍼널·일반 쿼리의 기존 한도와 공개 정책, PARTIAL 표시, run_id 선택, 집계 규칙은 유지한다. 초과 시 기존 오류로 중단하며 잘라낸 값을 전체 합계처럼 표시하지 않는다.

검증: 기존 대시보드 회귀와 거래 한도·리뷰/일반 한도 유지 검증. 실제 S3·Athena의 승인금액/상품금액은 모두 10,838,840,300원으로 일치했다. 운영 화면은 로그인 후 확인한다.
