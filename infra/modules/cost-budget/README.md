# 도쿄 월 비용 알림

AWS Budgets의 도쿄 Region 필터, USD 월 기준, 실비 10~100%를 10% 간격으로 초과할 때와 예측 100% 초과 알림을 이메일로 보낸다. 예산당 알림 5개 제한 때문에 actual-10-50, actual-60-100, forecast-100의 예산 3개로 나눈다. 세 예산은 동일한 비용·동일한 월 기준을 관측한다. 금액을 합산한 예산이 아니다. 금액에는 기본값이 없으며 사용자 확정값을 입력한다.

2026-10-24 사용자 확정값은 월 $200이다. 실비 $20·40·60·80·100·120·140·160·180·200 초과 알림과 월말 예상 $200 초과 알림이다. 100%를 넘은 뒤의 110% 이상 추가 단계는 구성하지 않았다. 새 월에는 해당 월 누적 비용으로 평가한다. 이미 여러 기준을 넘은 시점에 설치하면 복수 알림이 한꺼번에 올 수 있다. 실제 지출과 알림 사이에는 집계 지연이 있다.

크레딧·환불·세금은 제외한 비상각 unblended 비용을 사용해 지원 크레딧 때문에 사용 비용이 가려지지 않게 한다. 최종 청구액과 다를 수 있다. 글로벌 서비스나 다른 리전 비용은 도쿄 필터에 포함되지 않는다. Cost Explorer의 비용 집계 기준도 맞춰 비교한다.

SNS·CloudWatch 알람·IAM 역할·Budget Action은 만들지 않는다. 기존 RDS 장애 알림과 독립적이며 자원 정지·증설·권한 변경은 수행하지 않는다. 이메일은 민감 입력이며 output으로 노출하지 않는다.
